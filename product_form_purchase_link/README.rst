This module is deprecated and does nothing anymore.

Odoo 16.0 already shows the purchased quantity on product forms: the "Purchased"
smart button of the ``purchase`` module opens the purchase order lines of the
product. That button lists confirmed purchase orders only; requests for quotation
are found in the purchase order lines list. OCA closed the 16.0 migration of this
module because Odoo has the button.
