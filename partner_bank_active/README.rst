This module is deprecated and provides no functionality anymore.

Since Odoo 16, the ``active`` field on ``res.partner.bank`` is part of the
Odoo core: the ``base`` module defines the field and the standard form view
supports archiving bank accounts. The module is kept as an empty shell so
that installed systems keep updating cleanly until it is uninstalled.
